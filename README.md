# Tech Conference Schedule

A simple HTML project created as part of the [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design-v9/#workshop-tech-conference-schedule) curriculum.

## About the Project

This project presents a technology conference schedule organized by time and session track.

The table includes keynote presentations, web development workshops, accessibility sessions, design topics, and scheduled breaks.

## Features

- Structured HTML table
- Column and row headers
- Table caption
- Merged cells for breaks and lunch
- Accessibility attributes for table headers

## Technologies

- HTML5

## Learning Objectives

- Understand HTML table structure
- Organize information into rows and columns
- Use semantic HTML elements
- Apply basic accessibility principles

## Project Status

Completed as a learning exercise.
